# ⚡ 당일 단타 봇 경쟁 (Intraday Quant Trading Bots)

실제 1분봉 시장 데이터로 여러 트레이딩 봇이 **당일 단타**를 벌여 "**하루 수익률**"을
겨루는 모의 투자 시뮬레이터. 매매는 전부 모의(가상자산)지만, 가격·수수료·슬리피지·
레버리지는 실제처럼 반영한다. 각 봇은 **장중에 직접 종목을 선정**하고 **종가에 청산**한다.

## 🌏 국장 / 미장 분리

| 시장 | 유니버스 | 거래시간(현지) | 개장(한국시간) | 자본 |
|------|----------|----------------|----------------|------|
| **미장 (us)** | 미국 기술주 25종 | 09:30~16:00 ET | 22:30~05:00 | $10,000 |
| **국장 (kr)** | 국내 기술주 18종 (삼성전자·SK하이닉스·NAVER…) | 09:00~15:30 KST | 09:00~15:30 | ₩10,000,000 |

같은 봇들이 **미장에서는 미국 기술주, 국장에서는 국내 기술주**로 종목을 선정한다.
시장과 모드는 **각각 독립적으로** 선택·시뮬레이션된다.

## ⏱ 두 가지 모드 × 실시간

| 모드 | 동작 |
|------|------|
| **실시간 (today)** | 장중이면 **현재 시각까지의 1분봉만** 표시(진짜 실시간). 장 마감 시간대면 최근 세션을 **분 단위로 리플레이**(새로고침할수록 장이 펼쳐짐). |
| **전날 장 (prev)** | 직전 거래일 세션 **전체 백테스트**. |

> 한국 낮 시간엔 국장이 실시간으로 열려 있고, 미국 장은 밤(한국시간 22:30~)에 실시간이 된다.
> 장이 닫혀 있으면 자동으로 리플레이로 전환되어 봇들의 하루가 펼쳐지는 모습을 볼 수 있다.

## 빠른 시작

```bash
pip install -r requirements.txt
```

**웹 대시보드 (권장)** — 「대시보드 실행.bat」 더블클릭 또는:
```bash
python -m webapp.server --open      # http://127.0.0.1:5000
```

**CLI**
```bash
python main.py --market kr               # 국장 오늘(실시간/리플레이)
python main.py --market us --mode prev   # 미장 전날 장
python main.py --market kr --live        # 국장 실시간 반복 갱신
```

### 대시보드에서 볼 수 있는 것
- 🏁 **봇별 하루 수익률** 순위
- 📈 **봇 평가곡선** (장중 실시간/리플레이로 성장)
- 📉 **봇들이 고른 종목 주가 흐름** (시초가 대비 %)
- 💼 **봇별 보유 종목** + 시초가 대비 실시간 등락
- 🧾 **전 매매 기록** — 언제·어느 종목·매수/매도·수량·체결가·금액·수수료 전부
- 🔴 **LIVE / 📼 리플레이 배너** + 진행률, 자동 갱신(15·30·60초)

API 키 불필요(yfinance/Yahoo Finance 무료).

| 봇 | 전략 | 레버리지 |
|----|------|:---:|
| **Atlas** | 시초가 대비 모멘텀 상위 종목 추격 | 1x |
| **Nova** | VWAP 이탈 종목 반등 매수 | 1x |
| **Orion** | 오프닝 레인지(첫 15분) 돌파 | 1x |
| **Vega** | 최근 15분 단기 상대 모멘텀 | 1x |
| **Titan-3X** | 시초 모멘텀 상위 2종목 몰빵 | **3x** |

## 구조

```
투자/
├─ 대시보드 실행.bat        더블클릭 실행기(서버+브라우저)
├─ main.py                  CLI (--market us|kr, --mode prev|today, --live)
├─ quantbot/
│   ├─ config.py            시장(미장/국장)·유니버스·거래시간·자본·종목명
│   ├─ intraday_data.py     yfinance 1분봉 로더(시장별, tz/장상태)
│   ├─ live.py              실시간 클립 / 리플레이 커서
│   ├─ portfolio.py         가상 현금/주식, 리밸런싱, 마진·청산, 매매기록
│   ├─ strategies_intraday.py  봇 전략(종목선정+매매)
│   ├─ intraday_engine.py   분단위 시뮬, EOD 청산
│   └─ intraday_metrics.py  하루수익률·매매기록·종목흐름 + JSON
└─ webapp/{server.py, templates/index.html}   Flask + Plotly 대시보드
```

## 주의
교육·연구용 **모의 투자**다. 실제 주문은 없으며, 과거/장중 성과가 미래를 보장하지 않는다.
