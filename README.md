# ⚡ 당일 단타 봇 경쟁 (Intraday Quant Trading Bots)

실제 1분봉 시장 데이터로 여러 트레이딩 봇이 **당일 단타**를 벌여 "**하루 수익률**"을
겨루는 모의 투자 시뮬레이터. 매매는 전부 모의(가상자산)지만, 가격·수수료·슬리피지·
레버리지는 실제처럼 반영한다. 각 봇은 **장중에 직접 종목을 선정**하고 **종가에 청산**한다.

## 🌏 시장 4종 (국장 / 미장 × 우량주 / 급등주)

| 시장 | 유니버스 | 거래시간(현지) | 개장(한국시간) | 자본 |
|------|----------|----------------|----------------|------|
| **미장 (us)** | 미국 우량 기술주 25종 (AAPL·MSFT·NVDA…) | 09:30~16:00 ET | 22:30~05:00 | $10,000 |
| **국장 (kr)** | 국내 우량 기술주 18종 (삼성전자·SK하이닉스·NAVER…) | 09:00~15:30 KST | 09:00~15:30 | ₩10,000,000 |
| **미장 급등주 (us_hot)** 🔥 | 고변동 모멘텀/테마 기술주 24종 (TSLA·PLTR·SMCI·COIN·MSTR·IONQ…) | 09:30~16:00 ET | 22:30~05:00 | $10,000 |
| **국장 급등주 (kr_hot)** 🔥 | 고변동 KOSDAQ 테마주 18종 (에코프로비엠·레인보우로보틱스·위메이드·알테오젠·루닛…) | 09:00~15:30 KST | 09:00~15:30 | ₩10,000,000 |

**급등주 시장은 우량주와 완전히 동일한 7개 봇 전략을 그대로** 변동성이 큰 종목군에 적용한 것이다.
우량주는 장중 진폭이 작아 단타 손익이 잔잔하지만, **급등주는 같은 전략이라도 손익이 훨씬 격렬**하게 움직인다.
"우량주 vs 급등주"에서 같은 전략이 어떻게 다르게 작동하는지 비교할 수 있다.

시장과 모드는 **각각 독립적으로** 선택·시뮬레이션된다.

## ⏱ 두 가지 모드

| 모드 | 동작 |
|------|------|
| **실시간 (today)** | 장중이면 **현재 시각까지의 1분봉만** 표시(진짜 실시간). 장 마감 시간대면 최근 세션을 **분 단위로 리플레이**. 헤더의 **자동 갱신**(5·10·15·30·60초)으로 주기적으로 백엔드를 다시 호출한다. |
| **전날 장 (prev)** | 직전 거래일 **완료 세션**. 자동 갱신은 꺼지고, 대신 **🎬 타임랩스**로 장 시작부터 종가까지를 **재생**하며 각 봇이 *언제·무엇을·어떻게* 매매했고 수익률이 어떻게 변했는지 분 단위로 추적할 수 있다. |
| **📅 날짜 선택** | 헤더의 날짜 입력으로 **지난 특정 거래일**을 골라 그날 장을 본다(전날 장과 동일하게 완료 세션 + 타임랩스). yfinance 1분봉 한계로 **최근 약 30일** 이내만 가능. `✕`로 해제. |

### 🎬 전날 장 타임랩스 (갱신과는 별개의 재생 기능)
전날 장 모드에서 헤더의 컨트롤로 **장 개장→마감을 시간순으로 쭉 재생**하며, 각 봇의 수익률·순위·평가곡선이
어떻게 변해가는지 **바로바로 시각적으로** 본다:
- **▶ 재생 / ⏸ 정지** — 개장(약 20분차)부터 종가 청산까지 부드럽게 흐른다. 평가곡선·순위·종목 흐름·보유·매매기록이 시간에 따라 함께 움직인다.
- **⏮** — 처음으로 되감기.
- **속도 (1x~8x)** — 재생 속도.
- **스크럽바** — 특정 시점으로 직접 점프. 그 순간의 봇 상태(수익률·순위·보유·누적 매매)를 그대로 재현한다.

> 동작 원리: 전날 세션을 **한 번만** 받아둔 뒤, 재생은 **전부 브라우저 안에서** 분 커서를 흘리며 그 시점 상태를
> 즉시 다시 계산해 그린다. **갱신(서버 재호출)과 완전히 분리**되어 끊김 없이 매끄럽게 돌아간다.

> 한국 낮 시간엔 국장이 실시간으로 열려 있고, 미국 장은 밤(한국시간 22:30~)에 실시간이 된다.

### ⚠️ 실시간 데이터 지연(중요)
무료 데이터 소스(Yahoo Finance/yfinance)의 1분봉은 **약 15~20분 지연** 제공된다.
따라서 실시간 모드 화면은 항상 실제 시각보다 그만큼 뒤처진다 — **버그가 아니라 데이터 소스의 한계**다.
자동 갱신 주기를 아무리 짧게 줘도 이 지연은 줄지 않으며, 줄이려면 유료 실시간 시세 API가 필요하다.

## 📄 봇별 결과 보고서 (퀀트 개선용 자료)
`📄 보고서` 버튼(또는 CLI `--report`)으로 그날 장 결과를 봇마다 분해한다. **FIFO 라운드트립**(매수→매도 1쌍) 기준으로:
- **승률**(이익 라운드트립 비율), **손익비(Profit Factor)** = 총이익/총손실, **기대값**(트립당 평균손익)
- **평균/최대 보유시간**, **회전율**(총매수금액/자본), **총수수료**
- **평균 이익 / 평균 손실**, **최고·최악 매매**, **종목별 실현손익**

API 키 불필요(yfinance/Yahoo Finance 무료).

## 🤖 경쟁 봇 — 종목선정·매수·매도 원리 (정확한 규칙)

모든 봇은 공통적으로 이렇게 동작한다:
- **워밍업(`warmup_min`)** 분이 지나야 매매를 시작한다(개장 직후 노이즈 회피).
- 그 뒤 **의사결정 주기(`rebalance_min`)** 분마다 한 번씩, **현재 분까지의 1분봉만** 보고(look-ahead 금지)
  종목을 골라 **목표 비중(weight)** 을 정한다.
- 고른 종목은 **동일비중**으로 담는다(예: 3종목이면 각 `leverage/3`).
- 비중이 정해지면 포트폴리오를 그 목표로 **리밸런싱**(아래 [매매 실행](#-매매-실행-원리) 참조).
- **종가(세션 마지막 봉)에 전 종목을 청산**해 하루 실현수익을 확정한다(당일 단타, 오버나잇 없음).

`open_px` = 세션 첫 봉 가격(시초가), `last` = 현재 분 종가.

### Atlas — 시초가 대비 모멘텀 추격 (Intraday Momentum) · 1x
- 워밍업 5분 · 5분마다 의사결정.
- 각 종목의 **시초 대비 수익률** `r = last/open_px - 1` 계산.
- `r > 0`(오른 종목)만 골라 **내림차순 상위 3종목**을 동일비중 매수.
- 즉, "오늘 가장 강하게 오르고 있는" 종목을 쫓아 갈아탄다. 오르면 계속 보유, 순위에서 밀리면 교체.

### Nova — VWAP 이탈 반등 (VWAP Reversion) · 1x
- 워밍업 10분 · 3분마다 의사결정.
- **VWAP**(거래량가중평균가) = `누적(종가×거래량) / 누적(거래량)`.
- 이격도 `d = last/VWAP - 1` 가 **`-0.3%`보다 더 밀린**(`d < -0.003`) 종목들 중,
  **가장 많이 밀린 순(오름차순) 상위 3종목**을 동일비중 매수.
- "과하게 떨어졌으니 평균(VWAP)으로 되돌아온다"에 베팅하는 평균회귀 전략.

### Orion — 오프닝 레인지 돌파 (Opening Range Breakout) · 1x
- 워밍업 15분 · 5분마다 의사결정.
- **개장 첫 15분 고점** `or_high = 첫 15분봉 최고가`.
- `last/or_high - 1 > 0`, 즉 **첫 15분 고점을 상향 돌파**한 종목을 돌파 강도 내림차순 상위 3종목 매수.
- "초반 박스권을 뚫으면 추세가 이어진다"는 고전 ORB 기법.

### Vega — 최근 15분 단기 모멘텀 (Short-window Momentum) · 1x
- 워밍업 16분 · 5분마다 의사결정.
- **최근 15분 수익률** `r = last / (16봉 전 종가) - 1`.
- `r > 0`인 종목 내림차순 상위 3종목 매수.
- Atlas가 "시초 대비"라면 Vega는 "직전 15분"만 본다 — 더 짧은 호흡으로 빠르게 갈아탄다.

### Titan-3X — 3배 레버리지 시초 모멘텀 집중 (고위험) · **3x**
- 워밍업 3분 · **2분마다** 의사결정(가장 공격적).
- 종목선정은 Atlas와 동일(`r = last/open_px - 1`, 양수 상위)이되 **상위 2종목에 3배 레버리지로 몰빵**.
- 차입(현금 음수)을 일으켜 노출 300%. 손익이 3배로 증폭되며, **자본이 0 이하가 되면 즉시 강제청산(파산)** 되어 거래가 멈춘다.

### Claude — 적응형 리스크관리 모멘텀 (Claude가 직접 고안) · 1x
> 아래 [왜 기본 봇들의 수익률이 낮은가](#-왜-기본-봇들의-수익률이-낮은가--claude-봇-설계-근거) 분석을 바탕으로 만든 봇.
- 워밍업 15분 · 5분마다 의사결정.
- **시장 레짐 필터**: VWAP 위에 있는 종목 비율(breadth)로 장 분위기를 판단. 넓으면(강세) 투자, 좁으면(약세) **전량 현금**으로 자본을 지킨다. 잦은 전체청산↔재매수 휩쏘를 막으려고 **데드밴드**(진입 0.55 / 이탈 0.35)를 둔다.
- **3중 확인 진입**: `VWAP 위` + `시초 대비 상승` + `최근 5분 기울기 양수`일 때만 신규 매수(가짜 신호 배제).
- **승자는 두고 패자만 자른다**: 진입 신호가 잠깐 흔들려도 팔지 않고, **장중 고점 대비 −3% 추격손절**에 걸릴 때만 매도. 손절된 종목은 **10분 쿨다운**(같은 자리 반복 휩쏘 방지).
- 결과: 회전율·손절이 통제되어, 백테스트(최근 전날 장)에서 **국장·국장급등·미장급등에서 벤치마크(Sol)와 모든 액티브 봇을 앞섰고** 미장은 거의 보합으로 방어.

### Sol — 동일비중 보유 (벤치마크) · 1x
- 워밍업 1분 · 사실상 개장 직후 **1회만** 결정.
- 거래 가능한 **전 종목을 동일비중**으로 사서 **종가까지 그대로 보유**.
- 능동적 매매 없이 "그냥 시장 전체를 들고 있었다면?"의 기준선. 다른 봇들의 성과를 이 벤치마크와 비교한다.

## 🔬 왜 기본 봇들의 수익률이 낮은가 — Claude 봇 설계 근거

전날 장 **결과 보고서**(`--report`) 수치로 진단한 저수익의 원인:
1. **손절이 없다** — 모멘텀 봇들은 승률이 55~65%나 되어도 **손익비(PF)가 0.3~0.5**에 그친다. 이기는 매매는 작게 먹고, 지는 매매는 손절 없이 크게 잃어 손실이 이익을 압도한다.
2. **과매매(높은 회전율)** — 몇 분마다 종목을 갈아타며 회전율 4~6배. **수수료·슬리피지(편도 0.1%)** 가 누적되어 수익을 깎는다(총수수료가 자본의 0.5~0.6%).
3. **롱 온리, 현금 회피 없음** — 하락장에서도 항상 풀투자라 시장과 함께 손실(벤치마크 Sol도 하락일엔 −3%).
4. **노이즈 휩쏘** — "방금 오른 종목"을 쫓다가 곧바로 되돌림에 당한다(고가 매수→하락).

**Claude 봇은 이 네 가지를 정조준한다**: ①추격손절로 손실 차단(PF 개선), ②히스테리시스+긴 주기로 회전율↓, ③레짐 필터로 약세장엔 현금(자본 방어), ④VWAP·기울기 3중 확인으로 휩쏘 회피. 직접 `📄 보고서`에서 Claude의 PF·승률·회전율을 다른 봇과 비교해 보라.

## 🔁 매매 실행 원리

봇이 정한 목표 비중은 `Portfolio.rebalance()` 가 실제 매수/매도로 옮긴다:

1. **목표 주식수 계산** — 현재 총평가액 × 비중 ÷ 현재가. 비중 합이 레버리지 한도를 넘으면 비례 축소.
2. **먼저 매도** — 목표에서 빠지거나 줄어든 종목을 팔아 현금을 확보.
3. **그다음 매수** — 신규/증액 종목을 매수여력(현금, 마진봇은 자본×배수) 안에서 체결.
4. **거래비용** — 체결가에 **슬리피지 5bp**(매수는 비싸게, 매도는 싸게), 명목금액에 **수수료 5bp**.
5. **마진/청산** — 마진봇(Titan-3X)은 현금 음수(차입) 허용 + 차입 연이자 8%. 자본(현금+평가액)이 0 이하가 되면 **강제청산**.
6. **종가 청산(EOD flatten)** — 세션 마지막 봉에서 전 종목을 매도해 모두 현금화 → 하루 실현손익 확정.

## 💰 매도 수익률(실현손익)은 어떻게 계산되나

각 봇의 하루 수익은 결국 **매도로 실현**된다. 매매기록의 모든 매도에 대해 **평균단가(이동평균) 회계**로 손익을 계산한다:

- **매수** 시 그 종목의 누적 원가에 `매수금액 + 매수수수료`를 더한다 → 평단가 = 누적원가 / 보유수량.
- **매도** 시 실현손익 = `(매도금액 − 매도수수료) − 평단가 × 매도수량`,
  실현수익률 = `실현손익 / (평단가 × 매도수량)`.
- 종가 청산까지 끝나면 **매도 실현손익의 합 ≈ 그 봇의 하루 손익**이 된다(오버나잇 보유가 없으므로).

대시보드에서 확인:
- **🧾 매매 기록**의 `매도 손익` 열 — 매도 1건마다 실현 금액과 % (매수 행은 `–`).
- **봇 카드 / 💼 보유 종목 카드**의 `매도 실현` — 봇별 누적 실현손익.
- **📊 상세 지표**의 `매도실현` 열 — 봇별 매도 실현 수익률(시작자본 대비).
